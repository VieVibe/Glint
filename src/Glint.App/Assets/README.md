# Glint icon

森林绿底色 `#315E45`，暖白光芒 `#F5F6DB`。四角微光与左下方的短轨迹组成向右上方出发的符号，同时呼应搜索与快速启动。

- `glint.svg`：可编辑的矢量源文件。
- `glint.ico`：16、20、24、32、40、48、64、128、256 像素，透明背景、多尺寸 Windows 图标。
- `glint.png`：512 像素，用于界面标识。

在项目根目录运行 `scripts/generate-icons.ps1` 从 SVG 几何生成上述文件。当前使用基础直线和圆角矩形，无需外部图形工具。

脚本同时在 `artifacts/icon-previews/` 生成 16 像素的托盘检查图片与 160 像素预览。预览不进入 Git 提交。

程序文件和窗口使用同一 ICO；托盘按 Windows 小图标尺寸加载并持有独立副本，在退出时释放。

# 开发状态

当前版本为自用原型，支持应用索引、中文和拼音搜索、固定应用、自定义别名、键盘启动、托盘、便携应用添加与开机启动设置。

## 已完成的体验改进

- 按应用身份分配内置别名，区分微信与企业微信，避免名称片段误领类别别名。
- 精确名称优先，自定义精确别名优于内置别名；固定应用只影响相关性相同的结果。
- 开始菜单变化后延迟 1.5 秒合并刷新请求，每十分钟补充刷新一次。
- 刷新保留查询与仍在结果中的选中项，重复唤出时更新常用排序。
- 图标请求共享正在进行的任务，缓存失败结果，最多同时进行两次提取。
- 根据屏幕 DPI 与工作区限制窗口大小。
- 支持 `--exit` 正常退出并释放监听器、托盘和快捷键。
- 支持资源管理器和桌面文件的 Space 预览，默认置顶；再次按 Space、Esc 或失去焦点时关闭。
- 图片与视频直接预览，PDF 使用 Windows PDF 渲染并支持翻页，文字与 Office 文档提供有界文字预览。
- 预览关闭前标记关闭状态，避免原生激活回调重复关闭窗口导致整个进程退出。

## 自动检查

执行 `scripts/dev.ps1 check`，当前包含 74 项检查：

- 中文、英文、全角输入、拼音、首字母、内置与自定义别名匹配。
- 相关性、固定应用、使用频率排序与结果数量限制。
- 别名解析、长度限制与清空操作。
- 设置持久化、大小写兼容、旧版设置迁移与损坏文件检测。
- 真实 Windows 快捷方式解析与去重、文件变化触发刷新。
- 不同缩放、负坐标屏幕与小工作区下的窗口边界计算。
- 预览格式识别、中文与 UTF-16 文字、Office 文字提取、截断、取消、损坏文件和 XML 外部实体拒绝。
- 预览默认置顶，以及关闭期间失焦和重复关闭的窗口生命周期回归。
- 原生 PDF 渲染、极端图片双向解码尺寸、加载期间关闭、损坏图片与资源释放。
- 正常检查包含 100 次连续预览；使用 `dotnet run --project tests/Glint.Checks/Glint.Checks.csproj -c Release -- --stress` 可执行 1,000 次预览压力检查。

v0.2.0 已通过 1,000 次预览压力检查与依赖漏洞扫描，详见 [发布前检查](release-review-v0.2.0.md)。

检查程序另输出 2000 条模拟应用的纯搜索平均耗时，结果取决于设备，不包含界面、唤出或磁盘扫描。

## 已验证的运行行为

- 中文及拼音首字母查找应用，回车启动后收起窗口。
- 从其他应用通过全局快捷键唤出并聚焦，Esc 收起。
- 重复运行唤出已有实例，正常退出命令关闭运行实例。
- 在资源管理器选中图片后 Space 打开预览，再次 Space 关闭并回到原文件视图。
- 固定与取消固定，打开别名编辑窗口及输入框聚焦。

## 待补充验证

- 不同中文输入法的真实候选词确认，尤其 Enter 与 Esc 行为。
- 多屏混合 DPI 的真实设备测试；边界计算检查不替代设备测试。
- 商店应用启动覆盖、特殊快捷方式、多音字与更多别名。
- 开机登录、第三方快捷键冲突和长期常驻资源占用。
- 安装程序、签名及更新分发。
- 桌面、Windows 11 多标签资源管理器、更多 PDF 和视频解码器场景的实机覆盖。

# 产品范围与实现方向

Glint（轻启）是 Windows 应用快捷搜索工具：按快捷键唤出，输入应用名称，再用键盘启动。

## 产品取舍

- 只搜索应用，优先保证中文搜索、响应速度和操作手感。
- 数据保存在本机，无需账号或联网服务。
- 不追求极限安装体积；通过 C#、.NET 和 WPF 实现 Windows 原生集成。
- 暂不提供文件搜索、网页搜索或插件系统，不进行全盘扫描。

## 功能范围

- 快捷键唤出与收起、自动聚焦、冲突提示和快捷键切换。
- 开始菜单与 Windows 应用列表索引，支持手动补充便携应用。
- 中文、英文、全拼、拼音首字母、内置及自定义别名匹配。
- 相关性优先排序，使用次数和最近使用辅助排序，支持固定应用。
- 最多八条结果，上下选择、回车启动、Alt+数字直达、Esc 收起。
- 后台托盘、单实例、可选开机启动和本地设置持久化。

## 实现方向

后台建立并刷新应用索引，输入时只匹配内存记录。监听开始菜单变化并合并刷新请求，周期刷新补充商店应用变化。常规应用图标按需提取，缓存结果并限制同时提取数量。

中文输入法组合输入期间应优先处理候选词确认，避免误启动。快捷方式按真实启动目标和参数去重，保留不同参数对应的启动入口。

唤出 200 ms 内、搜索结果更新 50 ms 内是体验目标，需要在实际设备上测量；纯搜索基准不代表端到端性能。

## 后续重点

输入法、多屏混合缩放、商店应用覆盖、长期常驻资源占用，以及安装与更新流程。当前验证范围见 [开发状态](development-status.md)。

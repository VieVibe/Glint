轻启 Glint

这是 Windows 64 位便携版本，自带 .NET 运行时。
请完整解压 ZIP，保留文件夹内的所有文件，然后运行 Glint.exe。

Alt+Space：唤出或收起；若快捷键被占用，可在设置中切换到 Ctrl+Alt+Space。
输入中文、英文、拼音或首字母搜索应用。
↑↓：选择；Enter：打开；Alt+1 至 Alt+8：直达；Esc：收起。
Ctrl+D：固定或取消固定选中应用；Ctrl+E：编辑搜索别名。
F2：设置；F5：刷新应用列表。

文件快速预览：轻启在托盘运行时，在资源管理器或桌面选中文件，按 Space 打开置顶预览。
再次按 Space 或 Esc 关闭；Enter 使用默认应用打开。搜索框、地址栏和重命名中的空格照常输入。
支持常见图片、视频、PDF、文字文档，以及 docx / xlsx / pptx 的文字预览。
支持常见开发源码、配置、项目文件和补丁，含 Dockerfile、Makefile、.env、.gitignore 等文件。
源码预览带行号，常见语言和配置支持语法高亮。按 Ctrl+W 可切换自动换行。
直接滚动鼠标滚轮可缩放预览，Shift + 滚轮可上下浏览。点击底部百分比可恢复默认大小。
PDF 可用 ← → 翻页；Office 文字预览不保留原始排版和嵌入图片。
部分图片和视频需要系统解码器；不支持的格式会提示使用默认应用打开。
此功能默认开启，可在设置或托盘菜单中切换“Space 快速预览文件”。

收起后会继续在托盘运行。需要完全退出时，右键托盘图标，选择“退出轻启”。
开机启动默认关闭，可在设置中自行开启。开启后请保留程序所在位置。
个人设置保存在 %LOCALAPPDATA%\Glint\settings.json，不随软件包分发。

# 轻启 Glint v0.2.0

新增 Space 文件快速预览，并加固预览关闭、异常文件处理和资源释放。

## 下载与使用

下载 **Glint-win-x64.zip** 并完整解压，运行 **Glint.exe**，无需另行安装 .NET。支持 Windows 10 版本 2004 及以上的 64 位系统。

- 软件在托盘运行时，在资源管理器或桌面选中文件，按 **Space** 打开置顶预览，再按 **Space / Esc** 关闭；**Enter** 使用默认应用打开。
- 支持常见图片、视频、PDF、文字文档，以及 docx、xlsx、pptx 的文字内容。PDF 可用左右方向键翻页。
- 预览默认开启，可从设置和托盘菜单切换；不会接管搜索框、地址栏和重命名中的空格。
- 原有 **Alt+Space** 应用搜索、中文拼音匹配、固定和自定义别名继续可用。

## 稳定性与性能

- 修复预览关闭期间失去焦点、重复关闭导致整个应用退出的问题。
- 限制图片和 PDF 的渲染尺寸、同时加载数量及 Office 文档解压内容，避免异常文件占用大量资源。
- 资源管理器查询在后台执行，限制并发并设置等待时间；文件读取和解码不会阻塞预览窗口。
- 关闭时取消加载、释放图片、PDF 和视频资源；恢复原文件视图的焦点。
- 兼容异常设置中的空路径、大小写重复键、计数边界及不完整 Unicode 输入。
- 错误日志保存在 `%LOCALAPPDATA%\Glint\logs` 并限制大小，便于问题定位。

## 验证与已知边界

74 项检查通过，另完成 1,000 次图片、PDF、文字预览的连续加载与关闭检查，未出现崩溃、关闭后占用文件或超过检查阈值的资源增长。依赖扫描未发现已知漏洞。

Office 预览只显示文字，不保留原始排版和嵌入图片；部分图片、视频格式需要系统解码器。旧版 doc/xls/ppt 等不支持的格式会提供默认应用打开入口。多屏混合缩放、不同 Windows 11 资源管理器版本和更多视频编码仍需进一步实机验证；本版本未进行代码签名。

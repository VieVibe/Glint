# 轻启 Glint v0.1.0

Glint 的首个可下载版本：专注于中文搜索和键盘启动应用。

## 下载与使用

1. 下载下方的 **Glint-win-x64.zip**，完整解压到固定位置。
2. 运行文件夹中的 **Glint.exe**，无需安装 .NET。
3. 按 **Alt+Space** 唤出，输入应用名称，回车打开。
4. 使用托盘菜单退出；开机启动可在设置中自行开启。

适用平台：Windows x64。压缩包中附有中文使用说明。`SHA256SUMS.txt` 可用于检查下载文件的完整性。

## 主要功能

- 中文、英文、全拼、拼音首字母及常见别名搜索。
- 方向键选择、回车启动、Alt+数字直达、Esc 收起。
- Ctrl+D 固定常用应用，Ctrl+E 设置自定义别名。
- 后台索引和自动刷新，托盘常驻，可切换唤出快捷键。
- 数据保存在本机，无需账号或联网服务。

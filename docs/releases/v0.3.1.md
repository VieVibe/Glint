# 轻启 Glint v0.3.1

- Space 预览 Markdown（`.md`、`.markdown`）时默认显示排版，支持标题、列表、任务清单、引用、表格、强调和代码块。
- 点击“源码”或按 **Ctrl+M** 可切换排版与源码，滚轮缩放比例在两种视图间保留。
- Glint 自有内容采用 **MIT 许可证**，便携包附带完整许可证及第三方声明。

下载 **Glint-win-x64.zip** 后完整解压，运行 **Glint.exe**。更新前请从托盘退出旧版，再替换程序目录。可使用 **SHA256SUMS.txt** 校验下载文件。

Markdown 中的图片显示为说明文字，内嵌 HTML 以文本显示，结构过于复杂的文件会打开源码视图。连续预览的句柄压力检查在部分 Windows 环境仍可能超过阈值，v0.2.0 也能复现。

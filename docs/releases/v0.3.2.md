# 轻启 Glint v0.3.2

- 修复 Markdown 排版中显示原始 HTML 标签的问题。README 常用的 `<div align="center">` 现在会居中显示其中的标题和段落。
- 支持常见的 HTML 换行、分隔线和图片说明。排版视图会隐藏 HTML 注释和脚本，源码视图及代码块保留原文。

下载 **Glint-win-x64.zip** 后完整解压，运行 **Glint.exe**。更新前请从托盘退出旧版，再替换程序目录。可用 **SHA256SUMS.txt** 校验下载文件。

连续预览的句柄压力检查在部分 Windows 环境仍会超出阈值，v0.2.0 也能复现。

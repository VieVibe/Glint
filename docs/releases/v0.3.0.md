# 轻启 Glint v0.3.0

在资源管理器或桌面选中文件，按 **Space** 打开快速预览。

## 本次更新

- 新增 Go、Rust、Java、Kotlin、C/C++、Vue、Svelte 等源码格式，以及 Dockerfile、Makefile、.env、.gitignore、项目文件和 Git 补丁。
- 源码视图显示行号，常见语言和配置文件提供语法高亮。按 **Ctrl+W** 可切换自动换行。
- 预览时直接滚动鼠标滚轮可放大或缩小，按住 **Shift** 滚动可上下浏览。底部按钮支持 50% 至 300% 缩放，点击百分比可恢复默认大小。
- 重新排布文件信息、预览区和快捷键提示，窗口可拖动边缘调整大小。

## 下载与更新

下载 **Glint-win-x64.zip** 并完整解压，运行 **Glint.exe**。支持 Windows 10 版本 2004 及以上的 64 位系统，自带 .NET 运行时。更新时先退出旧版，再替换整个程序目录。个人设置存放在 `%LOCALAPPDATA%\Glint`。可使用 **SHA256SUMS.txt** 校验下载文件。

在本机连续运行 100 次预览的压力检查时，进程句柄增量超过检查阈值，v0.2.0 也能复现。该检查的每轮文件释放验证均完成。
